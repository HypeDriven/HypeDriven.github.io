HypeLLM

llm gateway
[ rust ]

A self-hosted routing gateway for LLM traffic: one controlled entry point in front of local and hosted model providers, built for operators who cannot let request content choose destinations or credentials.

  • ▸OpenAI- and Anthropic-compatible APIs (chat, responses, embeddings, messages) with streaming, failover, circuit breakers, and deterministic candidate ordering.
  • ▸Policy-based routing through model aliases, grants, denies, preferences, hard pins, residency requirements, and capability filters.
  • ▸Providers: llama.cpp, OpenAI, Anthropic, DeepSeek, and Moonshot/Kimi, plus an explicitly enabled generic OpenAI-compatible adapter.
  • ▸Security hardening: separate inference and management planes, strict parsers, destination pinning, credential isolation, RBAC, two-person policy publication, and an authenticated audit chain.
  • ▸Zero third-party runtime dependencies — the workspace builds offline and the admin UI ships first-party static assets only.
→source

HypeGPU

gpu tuning cli
[ c++ ][ cuda ]

A command-line tool for tuning a secondary NVIDIA GPU for inference. It searches core clocks, undervolts, and memory clocks against a fixed inference check, then reports estimated performance gains and power savings. Cards are selected by UUID, and tuning settings are restored when the search ends.

→source

HypeTerm

terminal mirror
[ rust ][ c++ ]

Watch and type into a terminal running on your machine, from your phone. A Rust relay carries the bytes both ways with a replay window, so a reconnecting phone picks up the scrollback it missed; the Android client is a C++17 core that renders the session and sends keystrokes back. Nothing runs on the device.

HypeTabs

[ c++ ][ typescript ]
